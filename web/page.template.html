Single-Press Keypad

Press each key once per letter. 0 is a space, 1 deletes, and * swaps the selected word for the next guess, and holding it finishes the word you're typing. # is punctuation: the model picks . , ! or ?, and between letters it's an apostrophe. Apostrophes are optional, so "dont" also gives "don't". Hold any number key to type that digit (hold 1 for "1", hold 0 for "0"). Digits end the word, so hold 4 then type 3837 for "4ever". # next to digits makes money and decimals: # 6 # 000 # 00 gives "$6,000.00". For call signs, spell the letters in exact mode (ke7aqa).

Hold # for exact spelling, for names and words the model doesn't know. Press a key repeatedly to cycle its letters and then its digit (2 = a, b, c, 2), and pause or press another key to move on. # cycles . , ? ! ' and 0 gives a space, or the digit 0 on a second press. On QWERTY, exact mode types the letter you tap. Hold # again to go back to predictive.

The word list includes names, places, brands and apps, with their usual capitalization (iPhone, McDonald's, YouTube).

Send copies the text, clears it and learns from it: the words you use and the words you use together get more likely, and a word you spelled exactly is guessed from its keys next time. That covers punctuation too. What it learns stays in this browser, kept for each model separately. Forget clears it.

Tap any word to see other words with the same keys. Picking one locks it, and the rest of the sentence re-decodes around it.

The QWERTY keyboard sends only each letter's keypad number (shown in the corner), so the model decodes it exactly as if you'd used the keypad. Keys grow and shrink in place with how likely each letter is to come next. A computer keyboard works the same way, and Tab finishes the word.

Runs entirely in this page. Model picks the word model: Phone (45,000 words), ESP32 (20,000) and Radio (5,000) are the same files the C decoder runs on those devices.
